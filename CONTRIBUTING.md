# Contributing

Thanks for helping improve Asteroid Map.

1. Open an issue for substantial behavior or scientific-model changes so assumptions can be discussed first.
2. Create a focused branch from `main`.
3. Add or update a regression test before changing behavior.
4. Run `npm ci` followed by `npm run check`.
5. Explain the user-visible change, scientific sources, limitations, and verification in the pull request.

Scientific claims should cite primary sources such as NASA/JPL documentation or peer-reviewed papers. Avoid presenting close approaches as predicted impacts, and keep uncertainty visible in UI copy and tests.

By participating, you agree to keep discussion respectful, specific, and focused on improving the project. Harassment, discrimination, threats, and publishing another person's private information are not acceptable. Report conduct concerns privately to `go@ziplyne.agency`.
